# Vacansee
Программа, которая получает информацию о вакансиях с платформы hh.ru в России, сохраняет ее в файл и позволяет удобно работать с ней: добавлять, фильтровать, удалять.

В разработке. Процент покрытия тестами - 97%.

## Использование
Клонируйте репозиторий:
```sh
git clone 
https://github.com/Oks-anaK/Course_work_Search_for_vacancies.git
```

Запустите проект из модуля [main.py](pythonproject11/src/main.py)

### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
poetry install
```

## Тестирование
Необходима установка pytest, pytest-mock. Наш проект покрыт тестами pytest. Для их запуска выполните команду:
```sh
pytest -v
```

### Зачем вы разработали этот проект?
Для удобного просмотра отфильтрованных вакансий.

1. [api_connect.py](pythonproject11/src/api_connect.py) содержит абстрактный класс для работы с API сервиса с 
вакансиями, и дочерний от него для работы с вакансиями с сайта hh.ru.
2. [vacancy.py](pythonproject11/src/vacancy.py) - модуль с классом Vacancy, для работы с вакансиями, поддерживает 
методы сравнения вакансий между собой по зарплате и валидирует данные.
3. [processing_data.py](pythonproject11/src/processing_data.py) содержит функцию, которая очищает HTML в текст 
(с использованием BeautifulSoup). А также функцию, которая создает список объектов Vacancy.
4. [open_files.py](pythonproject11/src/open_files.py) предоставляет абстрактный класс, который обязывает реализовать 
методы для добавления вакансий в файл, получения данных из файла по указанным критериям и удаления информации о 
вакансиях. И дочерний класс от абстрактного класса, для добавления, чтения, удаления информации о вакансиях в JSON-файл.
5. [main.py](pythonproject11/src/main.py) содержит основную функцию, которая объединяет другие, для выполнения поиска вакансий,
взаимодействия с API, обработки данных и сохранения в файл.
